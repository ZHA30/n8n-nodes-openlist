# @zha303050/n8n-nodes-openlist

Manage OpenList files and folders in n8n.

> [!NOTE]
> Install `@zha303050/n8n-nodes-openlist` from Settings → Community Nodes in self-hosted n8n running Node.js 24 or later.

## Features

Upload, download, inspect, list, search, copy, move, rename, and delete files or folders.

- **Files**: Get metadata, search, upload, download, copy, move, rename, and delete files.
- **Folders**: Create, get metadata, list contents, search, copy, move, rename, and delete folders.
